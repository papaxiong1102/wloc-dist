# WLOC audited distribution

This repository contains the minimal runtime files used by the owner's
Shadowrocket configuration. It is an audited distribution snapshot derived
from [`Yu9191/wloc`](https://github.com/Yu9191/wloc) at source commit
`eec07a8dc8de6dbaee8eac1fb376e4d03020154a`.

Approved interception hostnames:

- `gs-loc.apple.com`
- `gs-loc-cn.apple.com`

The complete mirrored source and history are maintained separately in the
owner's private repository. The upstream repository did not contain an
explicit license file when this snapshot was created; this repository does
not claim additional rights or grant a new license.
